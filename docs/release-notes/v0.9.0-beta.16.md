# PiedeMove 0.9.0 beta 16

## Italiano

- **Installazione più robusta e download più leggero.** Il codice nativo dell'app ora è compresso dentro l'APK e Android lo estrae all'installazione: il file da scaricare è più piccolo, e si evita il modo di caricarlo direttamente dall'APK con cui alcuni telefoni recenti segnalavano "pacchetto non valido" (beta 15).
- **Un APK solo arm64.** Accanto all'APK universale (va su tutti i telefoni, anche i vecchi a 32 bit, ed è quello che offre l'aggiornamento nell'app) c'è `piedemove-0.9.0-beta.16-arm64.apk`, molto più piccolo, per quasi tutti i telefoni dal 2017 in poi. Stessa chiave e stesso numero di versione: si aggiornano a vicenda.
- **Controllo prima di ogni versione.** L'APK di rilascio viene ora installato davvero su un emulatore Android prima di essere pubblicato.

**Installazione.** Si installa **sopra** la beta 9–15, senza disinstallare, e tiene preferiti e impostazioni. Da una beta più vecchia (fino alla 8) disinstalla prima. Scarica `piedemove-0.9.0-beta.16.apk` (o la versione `-arm64`) e aprilo dall'app File/Download. Controllo: `sha256sum -c piedemove-0.9.0-beta.16.apk.sha256`. Se compare ancora "pacchetto non valido", controlla che il file scaricato abbia la stessa dimensione indicata qui sotto tra i file della release.

**Dati e licenze.** Dati GTT: uso non commerciale (app gratuita, senza pubblicità). Linee regionali: Regione Piemonte, CC BY 4.0. Mappe, tracciati delle linee e percorsi pedonali: OpenStreetMap, ODbL; mappa di base OpenFreeMap / OpenMapTiles. Dettagli in [NOTICE.md](https://github.com/LucaCraft89/piedemove/blob/main/NOTICE.md). Data source: GTT S.p.A. - Gruppo Torinese Trasporti (https://www.gtt.to.it).

## English

- **Sturdier install, lighter download.** The app's native code is now compressed inside the APK and unpacked by Android at install: the download is smaller, and it avoids loading native code straight from the APK, the route on which some recent phones reported "package invalid" (beta 15).
- **An arm64-only APK.** Next to the universal APK (every phone, old 32-bit ones included; the one the in-app update offers) there is `piedemove-0.9.0-beta.16-arm64.apk`, much smaller, for nearly every phone since 2017. Same key and version code: either updates the other.
- **Checked before every release.** The release APK is now really installed on an Android emulator before it is published.

**Install.** Installs **over** beta 9–15 without uninstalling and keeps favourites and settings. From an older beta (up to 8) uninstall first. Download `piedemove-0.9.0-beta.16.apk` (or the `-arm64` one) and open it from the Files/Downloads app. Integrity: `sha256sum -c piedemove-0.9.0-beta.16.apk.sha256`. If "package invalid" still shows, check that the downloaded file has the size listed among the release's files.

**Tested.** 314 unit and widget tests, the golden Politecnico -> Via Cristalliera case, the on-emulator tour in CI, the release APK installed on the emulator, and the release-key check.

**Data and licences.** GTT data is non-commercial (the app is free, no ads). Regional lines: Regione Piemonte, CC BY 4.0. Maps, line geometry and footpaths: OpenStreetMap, ODbL; basemap OpenFreeMap / OpenMapTiles. See [NOTICE.md](https://github.com/LucaCraft89/piedemove/blob/main/NOTICE.md). Data source: GTT S.p.A. - Gruppo Torinese Trasporti (https://www.gtt.to.it).

**Reporting issues.** Settings > Segnala un problema, or open a [GitHub issue](https://github.com/LucaCraft89/piedemove/issues) with the phone model, Android version and a screenshot.
