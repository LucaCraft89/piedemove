# PiedeMove 0.9.0 beta 3

## Italiano

**Novità: le linee seguono GTT da sole.**
- Quando GTT pubblica nuovi orari, il tracciato di ogni linea rimasta uguale continua a essere disegnato sulle strade (prima sparivano tutti fino al prossimo aggiornamento dell'app).
- Una linea nuova o deviata, o un bus regionale, viene disegnata unendo le fermate con tratti **punteggiati** (approssimato, sempre segnalato).
- Ogni giorno GitHub ricostruisce le geometrie dagli orari GTT e da OpenStreetMap quando GTT cambia qualcosa; l'app le scarica da sola (al massimo una volta al giorno, solo con l'app aperta, file verificati). Nessun aggiornamento dell'app necessario.
- Questo APK include già le geometrie più recenti.

Tutto quanto c'era nella beta 2 resta (percorsi, tempo reale, viaggio guidato, Linee).

**Installazione.** Scarica `piedemove-0.9.0-beta.3.apk`, consenti l'installazione da fonti sconosciute, apri il file. Controllo: `sha256sum -c piedemove-0.9.0-beta.3.apk.sha256`.
**Importante:** l'APK è firmato con una chiave di debug generata dalla build di GitHub, diversa da quella di ogni versione precedente. **Disinstalla la versione installata prima di installare questa** (preferiti e impostazioni si perdono). Sparirà quando il progetto avrà una chiave di firma di rilascio.

**Dati e licenze.** Dati GTT: uso non commerciale (app gratuita, senza pubblicità). Linee regionali: Regione Piemonte, CC BY 4.0. Mappe, tracciati delle linee e percorsi pedonali: OpenStreetMap, ODbL. Dettagli in [NOTICE.md](https://github.com/LucaCraft89/piedemove/blob/main/NOTICE.md). Data source: GTT S.p.A. - Gruppo Torinese Trasporti (https://www.gtt.to.it).

## English

**New: lines follow GTT on their own.**
- When GTT publishes a new timetable, every line that did not change keeps its road-following route (before, all of them disappeared until the next app update).
- A new or rerouted line, or a regional bus, is drawn through its stops with **dotted** segments (approximate, always marked).
- Every day GitHub rebuilds the geometry from the GTT timetable and OpenStreetMap when GTT changes something; the app downloads it by itself (at most once a day, only while open, files verified). No app update needed.
- This APK already ships the newest geometry.

Everything from beta 2 stays (routing, realtime, live trip, Lines).

**Install.** Download `piedemove-0.9.0-beta.3.apk`, allow installs from unknown sources, open it. Integrity: `sha256sum -c piedemove-0.9.0-beta.3.apk.sha256`.
**Important:** the APK is signed with a debug key generated by the GitHub build, different from every earlier version's. **Uninstall the installed version before installing this one** (favourites and settings are lost). This goes away once the project has a release signing key.

**Tested.** 201 unit tests, the golden Politecnico -> Via Cristalliera case on the day's real GTT timetable, the on-emulator tour in CI, and the line rebuild's quality gates (0.62% of hops dotted, 0 gaps).

**Data and licences.** GTT data is non-commercial (the app is free, no ads). Regional lines: Regione Piemonte, CC BY 4.0. Maps, line geometry and footpaths: OpenStreetMap, ODbL. See [NOTICE.md](https://github.com/LucaCraft89/piedemove/blob/main/NOTICE.md). Data source: GTT S.p.A. - Gruppo Torinese Trasporti (https://www.gtt.to.it).
